# DongGyu Blog

**[https://donggyu-kang.github.io](https://donggyu-kang.github.io)**

강동규(DongGyu Kang)의 개발 블로그입니다. 백엔드 개발자로 성장하는 과정을 기록하며, 학습 내용과 자격증 취득 후기, 프로젝트 회고 등을 정리합니다.

## 소개

- 백엔드(Spring 등) 중심의 학습/개발 기록
- 정보처리기사, SQLD 등 자격증 합격 후기
- CS 지식, 인프라/DevOps, 프로젝트 회고 등 다양한 주제

## 기술 스택

[Jekyll](https://jekyllrb.com/)을 기반으로 [Clean Blog](https://startbootstrap.com/theme/clean-blog) 테마를 커스터마이징하여 제작했습니다. GitHub Pages로 배포됩니다.

- Jekyll (정적 사이트 생성)
- HTML / SCSS / Bootstrap
- GitHub Pages 배포

## 카테고리

- `Computer-Science` : CS 지식 정리
- `Dev & Frameworks` : 언어/프레임워크 학습 기록
- `Infra & DevOps` : 인프라, 배포 관련 기록
- `Retrospective` : 자격증 후기, 프로젝트 회고 등

## 로컬 실행

```bash
bundle install
bundle exec jekyll serve
```

빌드 후 `http://localhost:4000` 에서 확인할 수 있습니다.
